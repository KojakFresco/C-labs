# Отчет по лабораторной работе — Дейкстра (lab5)

## Цель работы
- Реализовать представление графа (список рёбер).
- Реализовать алгоритм кратчайшего пути — Дейкстра.
- Обеспечить CLI, загрузку/выгрузку графа и результата в файл.
- Реализовать интерактивный режим (ввод графа и параметров через консоль).
- Написать unit-тесты (GTest).
- Провести бенчмарки и подготовить результаты.

## Краткая структура проекта
- `graph.c/.h` — структура графа, функции загрузки/выгрузки, add_edge, init_graph, destroy_graph
- `dijkstra.c/.h` — построение adjacency list и реализация Dijkstra
- `priority_queue.c/.h` — мин-куча (Pair: vertex + distance)
- `main.c` — CLI: загрузка графа, запуск Dijkstra, вывод/запись результата, интерактивный режим
- `bench/bench.c` — бенчмарк (генерация случайных графов, измерение времени)
- `tests/` — тесты (GTest .cpp и альтернативные C-тесты)
- `CMakeLists.txt` — сборка, тесты и бенч

## Форматы входных и выходных данных
- **Файл**: первая строка — `N M` (число вершин и рёбер, 0-based индексация), далее M строк: `u v w` (ребро из u в v с весом w, целые неотрицательные).
- **Интерактив**: все параметры (N, M, рёбра, стартовая вершина) вводятся с клавиатуры. Результаты и граф сохраняются в файлы, указанные через параметры `--out-result` и `--out-graph`.

### Пример входного файла (`input.txt`):
```
5 7
0 1 1
1 2 1
2 3 1
3 2 1
0 3 4
3 4 1
2 4 2
```

## Описание реализации
- Представление графа и загрузка: структура `Graph` (см. `graph.h`), преобразование в adjacency list для алгоритма Дейкстры.
- Priority queue: бинарная куча на массиве `Pair { int vertex; long long distance; }` (`priority_queue.c`).
- Dijkstra: построение adjacency list, использование мин-кучи, массив расстояний `long long *dists`, INF = LLONG_MAX.
- Интерактивный режим: запуск через флаг `--interactive`, ввод графа с клавиатуры, сохранение результатов в файлы, указанные в командной строке.

## Использование

### Запуск с файлами:
```
./lab5_app --input input.txt --start 0 --out-result output.txt --out-graph out_graph.txt
```

### Интерактивный режим:
```
./lab5_app --interactive --out-result output.txt --out-graph out_graph.txt
```
Появится приглашение для ввода параметров графа и стартовой вершины. Результаты сохраняются в указанные файлы.

### Анализ результатов

- **Линейная зависимость**: Время выполнения алгоритма увеличивается линейно с добавлением рёбер, что соответствует сложности O((V+E) log V).
- **Стабильность**: Небольшие отклонения в сырых данных (raw_ms) на больших графах могут быть вызваны особенностями работы ОС или кеширования. Однако, средние значения и медиана остаются близкими, что подтверждает надёжность алгоритма.
- **Эффективность**: Алгоритм демонстрирует высокую производительность даже на графах с большим количеством рёбер, что делает его подходящим для использования в реальных приложениях.
