# Лабораторная работа №6

## Задача

Реализовать аналог утилиты `split` на Bash.

Скрипт позволяет разделять входной файл:
- по количеству строк;
- по количеству байт.

---

## Использование

```bash
./split.sh [OPTIONS] [FILE]
```

Если `FILE` не указан, данные читаются из `stdin`.

---

## Поддерживаемые опции

| Опция                     | Описание                                     |
|---------------------------|----------------------------------------------|
| `-p`, `--prefix=PREFIX`   | Префикс выходных файлов (по умолчанию `x`)   |
| `-a`, `--suffix-length=N` | Длина буквенного суффикса (по умолчанию `2`) |
| `-b`, `--bytes=SIZE`      | Размер части в байтах                        |
| `-l`, `--lines=N`         | Количество строк в части                     |
| `-h`, `--help`            | Вывод справки                                |

---

## Примеры использования

### Разделение по строкам

```bash
./split.sh -l 100 input.txt
```

Создаст файлы:

```text
xaa
xab
xac
...
```

Каждый файл будет содержать не более 100 строк.

---

### Разделение по байтам

```bash
./split.sh -b 1K input.txt
```

Создаст файлы размером до 1024 байт.

Поддерживаются суффиксы:
- `K` — килобайты
- `M` — мегабайты
- `B` — байты

---

### Использование собственного префикса

```bash
./split.sh -p part_ -l 50 input.txt
```

Результат:

```text
part_aa
part_ab
part_ac
...
```

---

## Особенности реализации

### Генерация суффиксов

Суффиксы генерируются в буквенном формате:
- `aa`
- `ab`
- `ac`
- ...
- `zz`
---

### Разделение по строкам

Для режима `-l`:
1. Файл считывается в массив строк;
2. Вычисляется необходимое количество выходных файлов;
3. Строки записываются в соответствующие части.

---

### Разделение по байтам

Для режима `-b` используется утилита `dd`.

Каждая часть создаётся путём:
- пропуска уже обработанных блоков;
- копирования фиксированного количества байт.

---

## Обработка ошибок

Скрипт проверяет:
- корректность аргументов;
- отсутствие конфликтующих режимов (`-b` и `-l`);
- существование входного файла;
- переполнение пространства суффиксов.

---

## Ограничения

- Поддерживаются только буквенные суффиксы (`a-z`);
- Максимальное количество файлов зависит от длины суффикса:

```text
26 ^ suffix_length
```

Например:
- длина 2 → 676 файлов;
- длина 3 → 17576 файлов.

---

## Запуск

Сделать скрипт исполняемым:

```bash
chmod +x split.sh
```

Запуск:

```bash
./split.sh -l 100 input.txt
```
